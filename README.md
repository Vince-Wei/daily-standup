# daily-standup

> 每日站会记录：三句话讲清楚今天，别让一天过得糊里糊涂。

## 简介

这里记录每天的工作节奏——昨天做了什么、今天要做什么、卡在哪。目的是逼自己每天做一次取舍，而不是被事情推着走。

## 目录结构

| 目录 / 文件 | 说明 |
| --- | --- |
| `2026/` | 按年份归档，每月一个文件，如 `2026-10.md` |
| `blockers.md` | 当前未解决的阻塞事项，解决后移出 |
| `templates/daily-template.md` | 每日记录模板 |

## 每日格式

一天一段，三段式：

```markdown
## 2026-10-19（周一）

- 昨天完成：
- 今天要做：（最多三件，多了说明没想清楚）
- 卡点：
```

## 使用原则

- 今天要做的事不超过三件，写不下说明优先级没排
- 卡点必须写具体，光写"进展不顺"没有意义
- 连续三天出现在卡点里的事，要么拆小，要么找人帮忙，别硬扛
- 没完成的不用自责，如实记录，第二天接着排
